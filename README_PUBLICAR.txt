CUIDAME - SITIO WEB GRATUITO PARA META DEVELOPERS

ARCHIVOS: index.html, privacidad.html, terminos.html, style.css, main.js, site-config.js, logo-cuidame.webp.

ANTES DE PUBLICAR
1. Abre site-config.js con Bloc de notas o VS Code.
2. Completa whatsapp con el número de empresa que QUIERES publicar, en formato 569XXXXXXXX, sin + ni espacios. Si tu WhatsApp comercial aún no está preparado, deja el campo vacío (el botón no aparecerá).
3. Completa email con el correo de contacto que QUIERES publicar, si lo tienes.
4. En legalName escribe el nombre real del responsable/negocio si corresponde. Revisa la política de privacidad y términos; el texto describe solo esta web estática.
5. Guarda el archivo.

PUBLICAR SIN PAGAR EN NETLIFY
1. Entra a https://app.netlify.com/drop
2. Arrastra la CARPETA CuidaME_Sitio_Web (no el ZIP) al área de publicación.
3. Netlify te dará una dirección pública HTTPS, por ejemplo https://nombre-aleatorio.netlify.app
4. Abre la URL y comprueba inicio, privacidad y términos desde el celular.
5. En Meta Developers, pega TU URL real, no el ejemplo.
   URL del sitio de la app: https://TU-SITIO.netlify.app/
   Política de privacidad: https://TU-SITIO.netlify.app/privacidad.html
   Términos: https://TU-SITIO.netlify.app/terminos.html
   Si Meta pide URL para eliminar datos de usuario, NO inventes un endpoint: necesitas una vía real para solicitudes de eliminación acorde al servicio y a los requisitos de Meta.

IMPORTANTE
- El sitio informativo NO conecta automáticamente el bot Python a WhatsApp.
- Para mantener tu WhatsApp Business actual en el móvil y conectarlo también a la API, se requiere una modalidad compatible de coexistencia, no una migración a ciegas.
- Publicar este sitio NO desbloquea por sí mismo el error 131031 (cuenta comercial bloqueada).
- El contenido incluye una política orientativa. Antes de recopilar información personal sobre adultos mayores, debes adaptar y aplicar una política de privacidad real y controles de seguridad.
- No pegues el token de Meta en archivos del sitio web: son públicos.
